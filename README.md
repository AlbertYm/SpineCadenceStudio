# Spine Cadence Studio 1.1.3

将 Spine 动画按指定频率采样，并在采样点之间保持姿态；保留总时长，生成可继续编辑的新工程。

## 获取与构建

本仓库提供源码。安装 Git 后，在 Windows PowerShell 中执行：

```powershell
git clone https://github.com/AlbertYm/SpineCadenceStudio.git
cd SpineCadenceStudio
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

构建结果位于 `dist\SpineCadenceStudio_1.1.3`，双击其中的 EXE。构建使用 Windows .NET Framework C# 编译器；不需要 .NET SDK。Spine 必须另行合法安装和激活，本仓库不包含 Spine 安装包或许可证。

修改和上传代码前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)；自动化代理还应遵守 [AGENTS.md](AGENTS.md)。

## 1.1.x 新增功能

完整变更见 [CHANGELOG.md](CHANGELOG.md)。

- 转换后可直接导出 `.skel`、`.atlas` 和 PNG，使用 Spine 4.1.24。
- 勾选导出后可选择独立的“游戏资源目录”，每个工程建立原名子文件夹，重名仅对目录追加序号。留空时放入工程结果的“游戏资源”子目录。
- “打包预设…”可加载自定义 Spine pack JSON。默认预设为最大 1024、正方形、4 的倍数、非 2 的幂、零间距、非预乘 Alpha、Linear 过滤。多页图集会保留全部 PNG。
- 支持附件网格变形 `attachments/deform`，包括稀疏顶点偏移。
- 兼容时间控制点交叉或越出关键帧区间的贝塞尔曲线，保留格式、有限数值及关键帧时间检查。
- 构建会复制 `binary-settings.json` 和 `screenshot.pack.json` 到 EXE 旁，请完整保留。

## 当前功能

输出文件夹带帧率后缀，但里面的 .spine 和 .json 保留原文件名；两种输出位置均适用。重复转换只对文件夹追加序号。例如 EmojiTY003_20fps\EmojiTY003.spine，下一次为 EmojiTY003_20fps_2\EmojiTY003.spine。

支持 Spine 4.1 骨骼贝塞尔曲线和动态插槽颜色采样，分别读取每个分量的时间/数值控制点，保持原动作缓入缓出节奏。采样点间保持姿态，动画总时长不变。
批次包含失败时，进度和结果显示为红色；全部成功为绿色；停止为黄色。每次开始清空上一批日志。

## 使用

1. 解压整个文件夹，双击 SpineCadenceStudio.exe。
2. “添加工程…”支持单选、多选；“添加文件夹…”递归查找 .spine，也支持拖入。
3. 设置姿态更新频率，默认 20 FPS。
4. 默认在原工程旁新建独立结果目录；也可以选择“指定文件夹”。
5. 确认 Spine.com 路径，点击“开始转换”。
6. 选择成功项，点击“打开输出”，打开新的 .spine 工程。

输出包括 .spine、JSON、引用贴图和转换记录。同名目录自动追加序号，原工程只读且核对哈希。
停止操作会完成当前文件后停止。事件时间不变。末尾不足一个采样间隔时保留原结束时间。
20 FPS 表示每 0.05 秒保持/更新姿态，不修改编辑器时间轴显示 FPS；不要另外改时间轴 FPS，以免改变总时长。

## 支持范围

支持 Spine 4.1 单骨架工程、多动画、骨骼线性/保持式/贝塞尔曲线（位移、旋转、缩放、剪切及拆分轴）、换图、绘制顺序、静态及动态颜色（rgba、rgb、alpha、rgba2、rgb2，含线性、保持式和贝塞尔曲线）、无外部音频的事件和引用的 PNG 贴图。
约束动画、序列附件、多骨架、外部音频、缺失贴图和未知通道仍会明确报错，不生成假成功结果。
JSON 往返不保证保留编辑器专属元数据。复杂静态约束与动画混合的最终观感需在目标项目中验证。

## 环境

Windows 10/11 x64，.NET Framework 4.8，已安装并激活且可启动的 Spine 4.1.24 Professional。
无需 Node、Python、.NET SDK、管理员权限或外部 AI。本工具不上传素材；Spine 启动器可能联网检查版本/许可证，不能保证离线启动。
EXE 未签名。单次 Spine 子进程超时为 180 秒，无自动重试。

## 更新与回退

这是独立的 1.1.3 目录，请启动该目录中的程序；旧窗口不会自动更新。
旧版和原工程保留，回退时直接使用旧程序或原工程。退出后删除工具目录即可卸载，生成的素材自行保留。
递归添加目录可能包含以前生成的工程，转换前检查列表。
支持反馈仅需版本、错误文字与相关通道，无需提供账号、许可证或密钥。
